# Portfólio para link na bio

Pequeno site estático pronto para hospedar no GitHub Pages ou Netlify.

Como usar

1. Abra `index.html` e substitua o conteúdo (nome, bio, projetos, e-mail).
2. Para testar localmente, abra `index.html` no navegador.

Deploy rápido (GitHub Pages)

- Crie um repositório e envie os arquivos.
- Nas configurações do repo, ative GitHub Pages a partir da branch `main` ou `gh-pages`.

Deploy com Netlify

- Faça login no Netlify e arraste a pasta contendo os arquivos para publicar.

Se quiser, eu adapto o design com suas cores, textos e links reais.
